# Bundled template fonts (offline)

TTF files for the template editor typography selector. Filenames follow the
[google_fonts](https://pub.dev/packages/google_fonts) bundled-asset convention
(`{ApiFamily}-{Weight}.ttf`, e.g. `OpenSans-Medium.ttf`).

Sources: [Google Fonts](https://fonts.google.com/) via `fonts.gstatic.com` hashes
matching `google_fonts` 6.x descriptors. OFL license texts are under `licenses/`.

Regenerate with `scripts/bundle_template_fonts.sh` (requires network).
